# Infinity Role Play Android Client

This is a customized research build of the upstream SAMP-Mobile GTA-2.10
branch.

## Infinity configuration

- App display name: `Infinity Role Play`
- Game server: `148.113.8.119`
- Game port: `26000`
- Android SDK: min 26, target 34
- Native ABIs: `armeabi-v7a`, `arm64-v8a`
- Cache directory expected by the upstream client: `/storage/emulated/0/GTA/`

## Building

Push the project contents to a GitHub repository, open **Actions**, select
**Build Infinity Role Play APK**, and run the workflow. The signed debug APK is
published as the `Infinity-Role-Play-Client-APK` workflow artifact.
